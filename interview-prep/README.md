## Every day

1. **10:30 AM, 30 min: mock interview.** The 6 questions are in the day file and on the mock page. Answer out loud, then type on the page. Next morning you get a 1-4 score per question.
2. **45 min: DSA in C++.** Starter files are in the day's `dsa/` folder. Say brute force -> pattern -> complexity before coding. Fill the header.
3. **45 min: the day's topic.** Tick the checklist; explain the two prompts out loud.
4. **5 min: log.** Fill the log table in the day file and one row in LOG.md. Commit: `dayNN: <what you did>`.

Saturdays swap to 30 min DSA + 60 min timed machine coding in Java. Sunday Day 3 is a review day.
